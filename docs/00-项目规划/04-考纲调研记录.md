# 考纲调研记录

> 记录日期：2026-08-29
> 目的：让「为什么以 DOFD v3.6 为基准」「权重从哪来」可追溯、可复核。
> 所有结论均来自本次会话实测抓取的官方页面与官方 PDF，非记忆或二手转述。

## 一、认证选型：三张同名证书的对比

市面上有三张都叫「DevOps Foundation」的证书，**考纲互不通用**：

| 维度 | DOFD（DevOps Institute / PeopleCert） | EXIN DevOps Foundation | DASA DevOps Fundamentals |
|---|---|---|---|
| 现行版本 | **v3.6** | Prep Guide Edition **202602** | 未标版本 |
| 题量 / 时长 / 及格 | 40 / 60min / 65% | 40 / 60min / 65% | 40 / 60min（非母语 75min）/ 65% |
| 开卷 | **是**（仅官方教材） | 否 | 否（可带草稿纸） |
| 官方公开权重 | 否（v3.4 有题数表） | **是**，细到 2.5% | 否 |
| 指定教材 | 官方 Learner Workbook | Oleg Skrynnik《DevOps – a Business Perspective》Van Haren 2018 | 需培训 |
| 有效期 | 3 年 + 60 CPD | 官方文件未写 | 终身 |
| 中文考试 | 是 | 是 | 官网未列 |
| 价格 | 官方无统一公开价，渠道 US$270–503 | 官方未公开；国内渠道约 ¥3500–5000 | €465（官网明码） |
| 进阶路线 | DevOps Leader / SRE / DevSecOps / CT / VSM Foundation | Professional → Master V2 | Platform Engineering / SRE Next Gen / DevAIOps 等 |

### 知识体系覆盖度（选型的决定性因素）

| 概念 | DOFD v3.6 | EXIN | DASA |
|---|:--:|:--:|:--:|
| 三步工作法 | ✅ | ❌ 未按名列入 | ⚠️ 隐含于 CALMS |
| CALMS | ✅ | ❌ | ✅ |
| 约束理论 | ✅ | ❌ | ❌ |
| SRE | ✅ | ❌ | ⚠️ 独立进阶认证 |
| DevSecOps | ✅ | ❌ | ✅ 独立进阶认证 |
| 可观测性 | ✅ v3.6 新增 | ❌ | ⚠️ |
| 平台工程 | ✅ v3.6 新增 | ❌ | ⚠️ 独立进阶认证 |
| DORA 指标 | ✅ | ❌ | ✅ |
| IaC | ✅ | ❌ | ✅ |
| ITSM | ✅ | ❌ | ✅ |

**结论**：EXIN 考纲严格按 2018 年出版的指定教材章节映射，SRE / DevSecOps / 可观测性 / 平台工程 / DORA 全部缺席。
DOFD v3.6 是三者中唯一覆盖当代 DevOps 全貌的，故选为基准。

## 三、关于「Blueprint」的重要澄清

PeopleCert 官网 DevOps Foundation 页面可下载的 **Certification Blueprint 只有一页**
（文件内部标题 `20260619 -DevOps Foundation Blueprint NEW LOGO`），内容为六个色块：
CALMS 五值、The Three Ways、Organization、Principles & Practices、Related Frameworks、Benefits。

**它是概览海报，不是考试大纲**——没有权重、没有学习目标、没有 Bloom 层级。
带「每个知识域最多几道题」的官方文件只有 DevOps Institute 的 **Examination Requirements**，
公开可得最新版为 v3.4。

## 五、v3.4 → v3.6 的内容增量

| M3 关键实践 | Monitoring and Observability、Value Stream Management、Platform Engineering |
| M4 框架 | VSM、SRE 被显式列入框架层 |
