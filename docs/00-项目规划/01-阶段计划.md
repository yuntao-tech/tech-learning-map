## P1 · 内容主干（ch00 + ch01–ch08）

按章交付，**每完成一章即可阅读**。建议顺序：ch00 → ch01 → ch02 → ch03 → ch06 → ch04 → ch05 → ch07 → ch08
（先打通「原则 → 实践 → 自动化」主轴，再补框架与文化）。

每章的固定交付物：

1. **章总览页**（改写 `index.html`）：本章知识地图局部图、考纲权重、学习目标、与相邻章的关系
2. **各小节页**：若干知识点卡，每卡严格遵循[六面模板](02-内容写作规范.md#知识点六面模板)
3. **章节总结页** `summary.html`：一页纸总结图、易混淆概念对比表、记忆锚点清单、本章练习入口
4. **图表**：每章至少 2 张自制图（流程 / 架构 / 关系 / 时间线之一）

## P2 · 练习系统

| # | 任务 | 产出 |
|---|---|---|
| P2-1 | 分章题库，每章按官方题数的 3–4 倍出题 | `data/questions/ch01.js` … `ch08.js` |
| P2-2 | 练习引擎：作答、判分、解析展开 | `assets/js/quiz.js` |
| P2-3 | 错题本：收集、复习、清空 | `assets/js/wrongbook.js`、`content/appendix/a5-wrongbook.html` |

题目数据格式（每题必备字段）：

```js
{
  id: "q-ch03-012",
  ch: "ch03",
  kp: "kp-3-3-delivery-vs-deployment",   // 反向链接到知识点
  stem: "……（中文题面）",
  stemEn: "……（英文题面，贴合考试语感）",
  options: ["A 选项", "B 选项", "C 选项", "D 选项"],
  answer: 2,                              // 0-based
  why: "为什么这个选项对",
  distractors: ["A 为什么错", "B 为什么错", "", "D 为什么错"],
  level: 1 | 2                            // Bloom 层级
}
```

**验收**：作答判分正确；错题写入 localStorage 并能在错题本读出；每题都能跳回对应知识点。
